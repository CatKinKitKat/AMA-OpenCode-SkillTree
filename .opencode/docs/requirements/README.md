# Requirements (examples)

Example requirement-lifecycle folders showing the clarify → specify →
architect → implement → test → secure → tag loop. **All fictional.**
The `RQ-*` folders are worked examples, not live tickets.

- `REQ-0000-example-distribution-list/`: full example: clarify, specify,
  tech-spec, tests, security review.
- `README.md`: this file.

Use the `complete-development` command to walk the loop on a real
requirement (after generifying it).
