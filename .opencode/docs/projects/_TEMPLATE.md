# Example Project Template

Copy this folder to start a new **example** project doc set. Replace all
placeholders. Nothing here is real.

## Files in a project set

- `OVERVIEW.md`: what the project is (fictional).
- `BUSINESS-TO-CODE.md`: how a made-up requirement maps to code.
- `KNOW-HOW.md`: gotchas, generic.
- `DETAILED_INFORMATION.md`: deeper notes, anonymized.

## Placeholders

| Placeholder   | Meaning                 |
|---------------|-------------------------|
| `the-project`        | fictional org           |
| `example.com` | fictional domain        |
| `the-backend` | generic service name |

Scrub any real identifier before committing.
