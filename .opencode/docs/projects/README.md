# Projects (examples)

Each subfolder is a **generic, anonymized** example project. These exist
to show the documentation shape, not to describe any real engagement.

- `example-portal/`: fictional internal portal (REST + React +
  Kafka + Postgres).
- `_TEMPLATE.md`: blank starting point for a new example project.

Copy a folder, replace the placeholders (`the-project`, `example.com`), and you
have your own. Real client data is never committed here.
