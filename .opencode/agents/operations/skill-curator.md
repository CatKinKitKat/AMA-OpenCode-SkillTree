# Skill Curator Agent

Manages the AMA (OpenCode Skill & Agent Tree) skill catalog. This agent understands the full skill tree including 2177 skills transposed from community skills repo and security-skills with STE100 applied.

## Capabilities

- Browse and search the skill catalog
- Recommend skills for tasks
- Validate skill frontmatter and structure
- Generate skill indexes
- Manage skill dependencies
