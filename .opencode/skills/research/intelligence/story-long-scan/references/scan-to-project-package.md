# 扫榜到开书项目包：参考流程

适用：用户要求“扫书/拆书后有灵感，直接在项目目录新建文件夹并产出大纲、金手指、世界观、人物关系、伏笔、简介、封面提示词”。

## 数据抓取顺序

1. 番茄：`https://fanqienovel.com/` 首页巅峰榜；`/rank` 可取阅读榜，但可能有字体混淆，榜面题材仍可用。
2. 七猫：优先 `https://www.qimao.com/paihang/`，DOM 内通常可见书名、作者、分类、状态、字数、简介、热度。
3. 起点：若 `qidian.com/rank` 触发验证码/安全验证，停止纠缠；标注“实时 DOM 未取到”，只作为平台调性参考。

## 分析方法

- 不抄具体表达，只抽象：题材骨、身份骨、冲突骨、爽点骨、升级骨。
- 免费平台优先看：标题直给、身份低位、冲突强、第一章能立刻翻盘。
- 番茄强项：脑洞、高武、怪物/规则/收容感。
- 七猫强项：历史边关、都市官场/高手、玄幻女帝/葬神/炼化、强简介钩子。
- 起点调性：规则闭环、升级逻辑、世界观纵深。

## 推荐项目文件包

在指定目录下创建一个语义清楚的 slug 文件夹，至少写：

- `README.md`：项目说明与文件索引。
- `扫书感悟.md`：数据来源、代表样本、趋势、借骨说明。
- `简介.md`：书名、备选名、一句话、正式简介。
- `大纲.md`：三幕/卷级结构、章级大纲、每章钩子与爽点。
- `正文计划.md`：总字数、章数、每章字数、黄金三章要求、禁忌。
- `金手指.md`：能力、限制、代价、升级路径、毒点规避。
- `世界观.md`：时代、地理、势力、规则。
- `人物关系.md`：主角团、反派、关系图。
- `伏笔铺垫.md`：伏笔、回收章、章尾硬钩。
- `封面生图提示词.md`：中文/英文提示词、风格、负面词。

## 验证

完成后列出目录文件，确认文件齐全；若用户要求了字数/章数限制，必须在 `大纲.md` 和 `正文计划.md` 两处出现。

可运行验证脚本：

```bash
bash ~/.agent/skills/community/oh-story-the agentcode/story-long-scan/scripts/verify-scan-project-package.sh "$BOOK_DIR" "8万" "10"
```
