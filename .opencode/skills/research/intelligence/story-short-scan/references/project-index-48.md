## 每项目标准文件结构

```
projects/{project-slug}/
├── 00-标题.md               # 书名
├── 01-一句话剧情.md          # 开头→结尾的一句话钩子
├── 02-大纲.md               # 三卷12章，每章标注字数
├── 03-人设与人物设定.md      # 主角+配角+弧光
├── 04-背景与世界观.md        # 核心设定+过审要点
└── 05-伏笔与铺垫.md          # 表格化伏笔清单+写法建议
```

## 流水线注意事项

- `write_file` 在高频批量创建时偶发丢失 `path` 或 `content` 参数（上下文压力 → 参数截断），导致文件写入失败但工具调用不报错或报 "missing required field"。**写入后必须抽样验证**：用 `terminal` 执行 `ls -la` 检查文件大小，或 `read_file` 读前 5 行确认文件实际存在且内容完整。若发现缺失文件（0字节或不存在），立即重写该文件。
