# 番茄扫榜→8万字短篇项目：2026-05 实战模式

## 适用场景

用户要求：到 `projects/` 仓库扫番茄小说，扫完后“像别的文件夹一样”产出项目设定文档，目标 8 万字短篇。

## 当前可靠流程

1. 打开 `https://fanqienovel.com/`。
2. 用 `browser_console` 提取首页「最近更新」表格：
   ```js
   (() => [...document.querySelectorAll('table tr')].slice(1).map(tr=>{
     const t=[...tr.querySelectorAll('td')].map(td=>td.innerText.trim());
     const a=tr.querySelector('td:nth-child(2) a');
     return {type:t[0], title:t[1], chapter:t[2], author:t[3], time:t[4], href:a?.href};
   }).filter(x=>x.href))();
   ```
3. 选 2-3 个最有迁移价值的样本开详情页，看标题、字数、简介、目录信号。
4. 从样本提炼“可迁移点”，不复制设定。
5. 新建 `projects/{slug}/`，固定落 9 个中文文档：
   - `扫书感悟.md`
   - `简介.md`
   - `大纲.md`
   - `世界观.md`
   - `人物关系.md`
   - `金手指.md`
   - `背景.md`
   - `封面提示词.md`
   - `伏笔铺垫.md`
6. 大纲按 8 幕，每幕约 1 万字，目标 8 万字；短篇正文阶段不分章，上传时整篇一次性粘贴。
7. 完成后验证：`search_files` 查 9 个 `.md`，`read_file` 抽查 `简介.md`，`terminal` 打印文件字节数。

## 2026-05 样本迁移方向

### 港风旧案 + 胶片证词

样本：旧案照片、港风双强、系统反套路、单元探案。

项目示例：`night-harbor-witness`

核心公式：母亲旧案 + 旧胶片 + 十三个女孩 + 男主活证人 + 公开证据。

### 民俗神像 NPC + 发癫破规训

样本：假装人机、发癫修仙、守夜灯与失踪女孩。

项目示例：`lamp-goddess-npc`

核心公式：女主被困神像背后 + 功德箱自动回复 + 七盏替命灯 + 守灯人七世等待。

### 现实反诈 + 遗物娃娃

样本：反诈系统、人偶修复、职业道具解析。

项目示例：`inheritance-doll-scam`

核心公式：母亲遗债 + 遗物娃娃吐工单 + 反诈中心男主 + 情感诈骗工坊。

## 标题原则

番茄短篇标题要情绪钩子前置、口语化、信息密度高：

- 好：`我妈留下87万债，遗物娃娃说她被骗了`
- 好：`我装成庙里人机后，守灯人说等我七世了`
- 好：`我妈死前那卷胶片，洗出了十三个我`

避免太文艺、太实体书、太含蓄。

## 写作立意要求

每个项目都要写清：

- 歌颂什么。
- 表达什么。
- 为什么不是猎奇设定，而是有情绪和价值落点。

常见立意：证据意识、女性互救、拒绝规训、记忆归名、清醒反诈。
