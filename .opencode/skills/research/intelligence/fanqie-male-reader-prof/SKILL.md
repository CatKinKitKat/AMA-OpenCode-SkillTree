# 用途

当用户要你：
- 看番茄热榜/书库，归纳男频读者喜好
- 按 `30万以下 / 30-50万 / 50-100万 / 100-200万 / 200万以上` 分析题材偏好
- 反推可写题材、爽点结构、避重策略

此技能给出一套低成本、可复用的采样法。

# 经验要点

1. 番茄书库页面可直接 headless 打开：
   `https://fanqienovel.com/library/stat1-count0/page_1?sort=hottes`
2. 页面常见字体混淆，正文与字数数字可能乱码；不要依赖逐字精读。
3. 即便乱码，以下信息通常仍足够稳定：
   - 筛选标签：`男生/女生`、`已完结/连载中`、各字数段
   - 标题结构
   - 简介中的可识别关键词
   - URL 中 `count0..count4` 对应字数桶
4. 此任务目标不是还原每本书内容，而是抽取市场偏好模式；标题、标签、题材词比正文细节更重要。

# 操作步骤

1. 打开男生最热书库首页：
   - `stat1` = 男生
   - `sort=hottes` = 最热
2. 先用页面脚本确认筛选项存在：
   - `30万以下`
   - `30-50万`
   - `50-100万`
   - `100-200万`
   - `200万以上`
3. 依次点击每个字数桶，抓取当前页面前 10-15 本样本。
4. 不必追求精确全文，重点提取：
   - 标题里的动作词：开局/刚穿/觉醒/无敌/满级/系统/首辅/跪下/继承
   - 题材词：修仙/末世/诡异/规则/官场/年代/港综/洪荒/西游/镖局/收容/卧底
   - 爽点词：杀伐果断/词条/模拟器/基建/经营/反腐/逆袭/团宠/病娇
5. 分桶总结：
   - 低字数看“点开率”
   - 中字数看“追更保持”
   - 高字数看“长线承载力”
6. 最终输出时，不要假装有精确统计；明确是“基于热榜样本的市场侧写”。

# 分析框架

## 跨桶共性

优先观察四件事：
1. 标题是否先给利
2. 主角是否有硬抓手（系统/词条/身份/规则权）
3. 是否旧赛道新挂法
4. 情绪是否走“压制→反杀→上升”

## 各字数段解释模板

### 30万以下
- 新书猎手盘
- 吃强钩子、快反馈、低理解门槛
- 容忍设定粗，不容忍慢热

### 30-50万
- 追更形成期
- 需要持续推进，不只是一章爆点
- 常见：熟题材 + 更狠主角 / 更新外挂

### 50-100万
- 稳定供给期
- 要主线、势力、身份成长
- 读者开始要求“这本能写久”

### 100-200万
- 中重度读者盘
- 看长线升级链、地图扩展、体系承载

### 200万以上
- 长陪伴盘
- 更接受传统大世界，但要求主角持续赢、地图持续开、回报持续升

# 常见结论模板

可稳定得出的男频偏好：
- 强主角
- 快反馈
- 清目标
- 大回报
- 熟设定新机制
- 长线升级感
- 别让主角憋屈太久

不太吃的：
- 纯氛围慢热
- 长时间压抑
- 设定太绕
- 爽点承诺大、兑现慢

# 输出建议

推荐按这四段说：
1. 采样范围
2. 跨桶共性
3. 各字数段用户侧写
4. 可落地写作建议

最后可补一句：
“男频读者要的不是新奇本身，而是熟赛道里更快、更狠、更稳的兑现。”

# 注意

- 页面乱码时，宁取模式，不硬解释细节。
- 不要把样本书内容写得像逐本书评。
- 不要只讲题材，要讲读者为何点开、为何续读、为何追长。
